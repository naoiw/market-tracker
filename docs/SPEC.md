# 画面と機能の仕様

## 概要

為替・暗号資産・株価指数の時系列データをブラウザで閲覧できる、読み取り専用の日本語Webアプリです。

## 画面と操作

- カテゴリー（すべて・為替・暗号資産・株価指数）でカード一覧を絞り込む。
- カードをクリック・タップすると、選択銘柄の価格グラフを表示する。
- グラフ表示期間は24時間・7日・30日・90日・全期間から選べる。
- 最新値、観測日時、比較データがある場合の変化率、取得元を表示する。
- データ未接続・表示期間にデータが不足する場合は値を捏造しない。
- スマートフォンではカードを2列にし、画面幅に応じたチャートとボタンを配置する。

## 取得データ

| 種類 | 銘柄 | 動作 |
| --- | --- | --- |
| 為替 | USD/JPY・EUR/JPY | ECBの日次参考レートをFrankfurter API経由で取得 |
| 暗号資産 | BTC/JPY・ETH/JPY | 公開利用を許諾されたフィードに対応 |
| 国内指数 | 日経平均・TOPIX | 公開利用を許諾されたフィードに対応 |
| 米国指数 | S&P 500・NASDAQ Composite | 公開利用を許諾されたフィードに対応 |

取得ワークフローの起動頻度は毎時1回ですが、ECB参考値自体の更新は通常1営業日1回です。株価指数や暗号資産はフィード未設定では空欄になります。

## データ品質・安全性

- 同じ銘柄・日時のデータは重複保存しない。日時の昇順で記録する。
- 価格は正の有限数に限定し、銘柄IDとタイムスタンプを検証する。
- 直近180日分を保持し、古い観測点を削除する。
- 外部APIのすべてが失敗したときは公開JSONを変更しない。
- APIキーはGitHub Actions Secretsで管理し、ブラウザ側に埋め込まない。
- 観測値の欠損・遅延を隠さず、データの性質と出典を表示する。

保存フォーマットは[システム設計](architecture.md)、利用権限は[データソースと利用条件](data-sources.md)を参照してください。
